Steps to run code:

1. Make a new folder for the project
2. Install python if u dont have it already
   - you can test that by running `python --version` in the command line (terminal on mac, cmd on windows)
4. Open terminal(or cmd on windows) and make a python venv (might have to google this one)
5. Install FastAPI in the venv: Run this in the terminal: `pip install "fastapi[standard]"`
6. run this to install the git repo: `git clone https://github.com/MehulWilliams/ImprovedTimeCardApp.git`
   - that will put the folder ImprovedTimeCardApp in whatever folder you're currently in.
  
7.  `cd` into the folder (in terminal/cmd)
8.  run `fastapi dev main.py`

9.  Feel free to contact mehul (riley on discord) for details/help
